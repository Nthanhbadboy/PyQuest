## Làm ngay

1. Chốt typed schema1 với ops allowlist,1..12beats,≤8ops/beat,caption/altText≤600
   Unicode code points,tokenGroup≤12; thêm giới hạn payload/code/geometry rõ để không
   cấp payload vô hạn qua một op. Renderer không execute code/URL/markup/I/O.
2. Authored fixtures cho mq1_01_s2 và mq1_03_s2. Copy8beat VI/EN lấy gói design59f7023;
   dùng identity input, không hardcode mọi lesson thành Robo. Fixture ops/source
   mapping phải nêu đúng câu lệnh hoặc output-prefix; numbers b2=chỉ dòng đầu, b3=hai
   dòng. Kiểm bằng expected deterministic fixture/engine reference, không nhận giá
   trị output do plan tự khai là nguồn sự thật.
3. Render ba layer phân quyền scaffold/Tutor/learner; controls trước/sau/replay,
   waitForLearner giữ beat. Learner ink/note có owner rõ hoặc injectable layer API
   không cho ops Tutor ghi/xóa; test isolation. Controller thuộc test host/lesson
   session tương lai, không app-global, không đặt trong chat sheet.
4. Validate toàn plan trước render; một op/reference/output/altText/size sai → reject
   nguyên plan, giữ bảng hợp lệ trước đó và fallback có nhãn; không bỏ connector rồi
   render nốt. Plain text như `<` hiển thị text, không interpret markup.
5. Token envelope của app phải khớp sessionId/revision/active turnId/locale; test
   stale/future/same-revision-different-turn/cancel/dispose bằng input giả lập. Đây là
   guard trong board boundary, **không** tuyên bố TutorSession/provider đã được nối.
6. Locale switch ở host thay copy của beat hiện tại, giữ beat/code/note/ink. CalmMode
   bỏ chuyển động, không skip nội dung; caption-only, không timer giả audio sync.

## Nghiệm thu

- Unit negative cases có tên rõ: sai version, empty/oversize, unknown op/object,
  foreign layer, wrong output scope/value, missing altText, stale/future/session/
  turn/locale mismatch, canceled/disposed; reject atomic, không mutation nửa chừng.
- Widget/golden: hai ví dụ × vi/en ×360×640 và390×844; font1/1.3/2, test host **không**
  lấy app clamp1.2 để giả đã kiểm font2. Dọc có thể cuộn, controls≥48 logical px,
  không overflow/chữ bị cắt; semantics + keyboard controls. Không claim device TalkBack.
- Replay/locale/next không phát lessonCompleted, spend energy, ghi score/quota/reward;
  API không có arbitrary callback cho ops ghi các dịch vụ đó.
- Baseline175ordinary +10render giữ nguyên hành vi; tăng tests có giải thích, không
  skip/xóa/nới tests. Analyze sạch; output/evidence gắn tested_code_commit/run SHA.
- Publish ảnh Flutter từ renderer test host, ghi rõ **chưa nối LessonScreen/AI/voice**.
  Không thêm hidden production route/debug launcher chỉ để chụp ảnh.
