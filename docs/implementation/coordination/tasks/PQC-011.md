### 2.1 Entry/layout và hành vi ExampleStep

- Gắn bảng **inline** bên dưới code editor/run result trong cùng `LessonScreen` scroll; không mở bảng bằng `showModalBottomSheet` và không đặt controller trong `TutorPanel`.
- Trên đúng hai step được catalog hỗ trợ, thay `CodeView` tĩnh bằng `CodeEditor` khởi tạo từ code gốc của `ExampleStep`. Chạy code đã chỉnh sửa qua đường `_execute` hiện có. Đây là sandbox minh họa, không phải exercise: giữ nguyên điều kiện Continue hiện có; không gọi `_markSolved`, không tăng `_solved`, không phát `exercise_solved`/`lesson_completed`, không ghi đáp án hay progress.
- Giữ code gốc bất biến làm nguồn authored/reference. `BoardView.codeText` nhận code learner đang sửa; khi khác source, renderer phải giữ nội dung nguyên văn và dùng cảnh báo `codeMismatch` sẵn có để tắt highlight không còn đúng. Không tạo plan/reference từ code learner hoặc từ text trong plan.
- Khi learner sửa hoặc chạy ô code, đánh dấu hành động cho beat `waitForLearner` bằng API board phù hợp. Nút Previous/Replay/Next của bảng chỉ đổi beat/ack wait; tuyệt đối không gọi `_next`, Continue, grading hay event hub của lesson.
- Header bảng phải hiện badge authored VI/EN và đúng nhân vật/portrait từ `CastRegistry.tutorForSkill(lesson.skill)`. Không hiển thị sentinel `__from_cast_registry__`, không hardcode cùng một nhân vật cho mọi plan. Ẩn scaffold debug IDs (`mq1_01`, `mq1_01_s2`, `nova`); LessonScreen/header mới là scaffold thân thiện cho trẻ.
- Dùng chế độ embedded của `BoardView` để toàn bộ lesson dùng **một** vertical scroll owner, tránh nested vertical scroll. Embedded mode ẩn debug scaffold; standalone scrolling/debug scaffold mặc định vẫn giữ cho tests/previews hiện hành.

### 2.2 Ownership/lifecycle

- `_LessonScreenState` là owner của `BoardController`, code editor/controller và scroll/focus state. Tạo board controller chỉ khi step id có trong catalog; owner gồm lesson id + step id + `sessionId` duy nhất cho instance LessonScreen.
- `TutorPanel` là route tạm, chỉ giữ chat/transcript như hiện tại. Mở/đóng/reopen TutorPanel không dispose/recreate controller, không reset beat, learner model, code text/selection, run output, scroll position hoặc focus đã có.
- Locale đổi: gọi `BoardController.setLocale` trên controller hiện hữu; copy, badge và labels đổi ngôn ngữ nhưng beat, learner data, source code, input/selection và run result giữ nguyên. Chỉ hỗ trợ hai locale `vi`/`en`; locale khác theo fallback hiện tại của `BoardLabels`.
- Khi đổi step, rời LessonScreen hoặc teardown: dispose đúng owner; callback async đang bay phải kiểm tra mounted/generation/controller identity trước khi apply. Plan cũ không được xuất hiện ở lesson/step mới.
- Nếu một step không có plan authored, không tạo controller/blank panel; lesson hiện tại tiếp tục hiển thị và chạy như cũ.

### 2.3 Asset composition và trusted reference

- Nguồn runtime duy nhất là `app/assets/data/tutor_board_plans.v1.json` và `app/assets/data/tutor_board_authored-copy.v1.json`; bundle keys tương ứng `assets/data/tutor_board_plans.v1.json` và `assets/data/tutor_board_authored-copy.v1.json`. Cập nhật board tests để đọc đúng asset nguồn, không duy trì hai bản dữ liệu có thể drift.
- Thêm loader/composer trong `app/lib/modules/tutor/board/`. Loader đọc bằng `AssetBundle`, giới hạn kích thước, kiểm `contentVersion`/`schemaVersion`, nối copy với plan bằng `beatId`, kiểm chính xác tập beat và `waitForLearner`, rồi gọi `validateBoardDocument` trước khi `applyPlan`.
- `lessonId`, `stepId`, locale list, `registeredObjects` allowlist và `characterId` là host-owned. Dùng catalog Dart riêng keyed theo hai step để cấp IDs; **không** lấy `registeredObjects` từ JSON plan. Thay placeholder character bằng `CastRegistry.tutorForSkill(lesson.skill)` trước khi decode/validate. Thêm test chứng minh thay các giá trị này trong payload không mở rộng quyền host.
- `DeterministicReference` chỉ được dựng từ `ExampleStep.code` bất biến, bằng một instance cô lập của `SimulatedPythonRuntime` với `AppServices.config.pythonLimits`; chạy code nguồn trusted và từng dòng nguồn cần thiết, rồi cấp output cho validator. Không dùng chung runtime instance với nút Run để reference build không thể chiếm/cancel lượt chạy của trẻ. Không chạy `statement`, `value`, `code`, hay bất kỳ nội dung nào do plan/learner cung cấp để tạo oracle. Plan output chỉ được **so sánh** với output engine vừa tính.
- Lỗi bundle/JSON/schema/locale/IDs/reference/foreign step: reject toàn plan, không render một phần, giữ trạng thái bảng hợp lệ trước đó nếu có và hiện fallback authored có nhãn; không làm crash hoặc chặn lesson. Không fallback sang Tutor AI hoặc tự áp output không xác minh.
- Hiện gói plan/copy chứa `registeredObjects` và sentinel character cho test composition. Runtime loader phải coi chúng là dữ liệu không có thẩm quyền; registered IDs và character đều thay bằng host values nói trên.
