## Contract

- Preference system | explicit(supported BCP47 tag), không lưu effective locale như
  lựa chọn người dùng. Supported vi/en; duyệt danh sách OS theo ưu tiên, regional→base;
  không match → **English**. System không là tag gửi voice. Trạng thái matched/fallback
  phải phân biệt được để Settings tương lai hiển thị đúng.
- Key mới `ui_locale_preference`: system|vi|en. Dùng raw, không getter lang:
  new valid → dùng; new present-invalid → system; new absent+legacy rawvi/en → explicit;
  cả hai absent/legacy invalid → system. Không xóa legacy key chỉ để đơn giản hóa test.
- Migration idempotent; không đổi DB schema. Dữ liệu load xong vẫn phân biệt unset và
  explicitvi. OS list thay đổi chỉ ảnh hưởng mode system, không ghi prefs tự động.
- Persist explicit/system khi người dùng chọn; lỗi write không báo “đã lưu”. Session
  selection có thể có hiệu lực, nhưng restart phải đọc giá trị persisted thật; cung
  cấp state/error cho UI sau này. Không làm các setter âm thanh/calm/intro mất dữ liệu.
- Giữ adapter PqLang cho systems cũ; lang getter/setLang phải tương thích đủ tests
  hiện có. Không tự fallback enumvi rồi biến nó thành explicit override. Ghi rõ điểm
  nào chưa có root OS update cho tới015; không claim UI/live voice đã đổi theo hệ thống.
