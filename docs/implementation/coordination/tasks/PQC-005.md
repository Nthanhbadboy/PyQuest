# PQC-005 — Regenerate `app/pubspec.lock` cho nhóm dependency audio

- work_order: `PQC-005`
- scope: runtime
- gate_note: `runtime` — `app/pubspec.lock` là dependency change, cần design + user ủy quyền riêng
- status: `BLOCKED` — sandbox code không có Flutter SDK và không truy cập được
  `pub.dev`/`storage.googleapis.com`; tự cài SDK ngoài phạm vi phiên
- vì sao mở: `app/pubspec.yaml` khai báo `flutter_sound ^9.30.0`, `record ^6.1.2`,
  `web_socket_channel ^3.0.3`, `audioplayers ^6.1.0` nhưng `app/pubspec.lock` **không
  có mục audio nào** → mỗi lần CI chạy `flutter pub get` là resolve lại từ đầu
  (log run 93: `+ flutter_sound 9.30.0`, `+ record 6.2.1`, `+ record_android 1.5.2`,
  `+ web_socket_channel 3.0.3`). Build không vỡ nhờ CI resolve, nhưng lockfile không
  còn mô tả đúng lần resolve đó.

## Việc

1. Trên máy có SDK: `cd app && flutter pub get`, kiểm tra diff `pubspec.lock` **chỉ**
   thêm/cập nhật các package audio/websocket, không đổi phiên bản khác một cách vô ý.
2. `flutter analyze --no-fatal-infos` + `flutter test --exclude-tags render` tại commit đó.
3. Commit riêng, message nêu rõ đây là lockfile sync, không trộn vào commit asset hay test.

## Cấm

Sửa tay `pubspec.lock`; đổi version constraint trong `pubspec.yaml` (mỗi package đều có
lý do: `flutter_sound` cho PCM sink, `record` cho capture `voiceCommunication`,
`web_socket_channel` cho Live); `flutter pub upgrade` toàn bộ.

## Nghiệm thu

* `pubspec.lock` chứa đúng bộ phiên bản mà CI đã dùng; CI vẫn xanh như trước.
* `docs/implementation/coordination/TASK_BOARD.md` cập nhật: hàng đợi PQC-002/PQC-003
  không còn lý do "lockfile stale" ở phần environment note.
