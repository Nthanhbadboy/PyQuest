## Việc

1. `app/test/activity_sheet_thumbnails_test.dart`: với từng activity id trong
   `activityRegistry`, mở sheet (dùng helper `pumpFor`/`loadAppFonts` như
   `render_screens_test.dart`), assert `tester.takeException()` null sau khi asset được
   giải mã (`tester.runAsync` để `AssetImage` load thật), assert ảnh hiển thị 104×104
   logical qua `RenderImage`/`DecorationImage`, và assert nhãn/không có chữ bake trong ảnh.
2. Thêm state khoá của Bug Hunter (chưa đủ điều kiện mở) để chứng minh thumbnail vẫn
   hiển thị đúng khi hoạt động bị khoá.
3. Một test "asset budget" rẻ: dung lượng 6 file `assets/images/thumb_*.webp` nằm
   trong ngưỡng đã duyệt và mỗi file là WebP, vuông, cạnh ≥ 256 — để lần thay art sau
   không âm thầm phình.
4. Ghi vào `docs/implementation/coordination/EVIDENCE.md` (tạo mới) định dạng chuẩn
   cho cặp trước/sau: viewport, trạng thái dữ liệu, nguồn (Flutter render test hay
   emulator), commit, và cách dựng lại.
